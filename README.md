# Google Birthday Wall 🎉

A collaborative 100x100 virtual grid wall built to celebrate Google's Birthday! Brought to you by **Google Developer Student Clubs • NIT Andhra Pradesh**.

## Features

- **Massive 100x100 Grid:** 10,000 individually claimable cells to leave your mark.
- **Dynamic Blocks:** Claim massive 5x5 blocks to upload high-quality pictures and GIFs that span seamlessly across the grid.
- **Glassmorphism UI:** A sleek, sticky navigation bar and beautiful interactive tooltips.
- **Smart Collision Detection:** Grid algorithms prevent users from overlapping claims or going out of bounds.

## Tech Stack

- **Frontend:** React, Vite, Tailwind CSS, Lucide Icons
- **Backend:** Node.js, Express, MongoDB
- **Storage:** Cloudinary (for fast image and GIF delivery)

## Getting Started

1. Add your Cloudinary and MongoDB credentials to `server/.env`.
2. Run `npm install` in both the `client` and `server` directories.
3. Start the dev servers by running `npm run dev` in both directories.
